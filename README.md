# Monthly Sales Trend Analysis

## Project Overview
This project demonstrates monthly sales analysis using Microsoft Excel. It focuses on organizing sales data by month, calculating monthly revenue, and visualizing sales trends using a line chart.

## Objectives
- Summarize sales by month.
- Practice date grouping and chronological sorting.
- Calculate monthly sales and order counts.
- Visualize trends using a line chart.

## Tools Used
- Microsoft Excel
- Monthly aggregation
- SUMIFS and COUNTIFS formulas
- Line Chart

## Project Structure
- `Veda_Task_17_Monthly_Sales_Trend.xlsx`
  - Raw Data
  - Monthly Summary
  - Dashboard
  - Mini Guide

## Key Deliverables
1. Monthly sales summary table.
2. Monthly sales trend line chart.
3. Annual sales and order totals.
4. Instructions for updating the dataset.

## Dataset Note
The workbook currently contains illustrative synthetic sales data for demonstration. It does not represent actual Veda Technology sales.

## Learning Outcomes
- Date formatting and grouping.
- Monthly sales calculations.
- Chronological data organization.
- Sales trend visualization.
